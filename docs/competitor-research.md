**빈자리:** *변호사가 직접 쓰고, 가격이 투명하고, 빠른* 서비스. 저가형 몇 곳이 이미 이 자리를 노리고 있으니 차별점이 필요합니다.

## 2. 주요 경쟁사 상세

### ① 99내용증명 — 앤드 법률사무소 (99law.co.kr/certificate)
- **운영:** 변호사 사무소
- **가격:** 착수금 99,000원부터(VAT·우편료 별도). 상담+작성+발송+후속 상담 포함 "10만 원대". 기본 3페이지 기준
- **강점:** 브랜드 이름 자체가 가격("99"). 상담 후 **영업일 24시간 안에 초안**. 수정 횟수·페이지 기준을 명시. 우체국과 카카오 전자 발송 모두 가능
- **참고:** 과거에 15분 상담 33,000원부터라는 안내도 있었음

### ② 법률사무소 헤아림 (hearimlaw.com/certify)
- **운영:** 변호사 사무소
- **가격(3단계):**
  - 의뢰인이 쓴 글을 변호사 명의로 그대로 발송: 77,000~99,000원/건
  - 법률 양식으로 바꿔서 발송: 209,000원/건
  - 법률 검토(전화 상담) 후 발송: 550,000원/건
- **강점:** "얼마나 손대느냐"에 따라 단계를 나눠 이해하기 쉬움 → **벤치마킹 1순위 가격 구조**

### ③ 내용증명의 신 (naeyong.kr)
- **운영:** 현직 변호사, 작성부터 발송까지 원스톱
- **가격:** 작성 30만 원 / 상담 후 작성 40만 원 / 당일 발송(Express) 80만 원
- **방식:** 게시판에 사연을 올리면 변호사가 답변한 뒤 작성·발송
- **강점:** "급행" 옵션으로 단가를 높임

### ④ 김&리 법률사무소 (krlaw.kr)
- "24시간 내용증명", 변호사와 직접 소통, 빠른 발송 강조. 가격은 "사건에 따른 합리적 비용"으로 공개하지 않음

### ⑤ 크몽 변호사 판매자들
- 3만 원(10분 전화 상담) → 일반 44만 원 / 쟁점이 추가되면 55만 원 (VAT 포함, 결제 수수료 4.5% 별도)
- 다른 판매자: 검토 후 그대로 발송 22만 원 / 변호사 작성 후 발송 33만 원
- 평점 5.0에 리뷰 278건인 판매자도 있음 → **고객은 리뷰 수를 중요하게 봅니다**

### ⑥ 참지마요 (chamjimayo.com) — 간접 경쟁
- "1분 셀프 내용증명", AI 작성. 전자 발송 19,900원 / 우체국+전자 24,900원
- 변호사가 아니므로 우리는 **"분쟁으로 번질 사건이면 처음부터 변호사에게"**라는 메시지로 대응

## 3. 경쟁사 공통 패턴 (따라 할 것)
1. **가격을 첫 화면에 공개.** 정액 + 단계별 구조
2. **속도를 약속.** "24시간 초안", "당일 발송"
3. **"변호사 명의"를 강조.** 상대방이 받는 심리적 압박을 소구점으로 씀
4. **사건 유형별로 진입.** 전세보증금, 대여금, 물품대금, 계약 해지, 명예훼손 등
5. **발송 방법 선택.** 우체국 등기 내용증명 / 전자 내용증명
6. **신청 단계는 적게.** 사연 입력 → 결제 → 초안 확인 → 발송

## 4. 경쟁사 약점 (우리의 기회)
- **가격 함정:** "부터" 가격, VAT·우편료 별도, 수정 횟수 제한이 눈에 잘 안 띔 → **우리는 "모두 포함한 총액"을 표시**
- **사후 대응 공백:** 상대가 답장하지 않거나 반송되면 어떻게 할지 안내가 거의 없음 → **"반송·무응답 시 재발송·공시송달·지급명령 연계" 패키지**
- **진행 상황이 안 보임:** → 접수, 초안, 확인, 발송, 수령까지 **알림톡으로 단계별 안내**
- **누가 쓰는지 모름:** → 변호사 실명, 사진, 등록번호, 직접 쓴다는 원칙을 공개

## 5. 포지셔닝 제안

**한 줄 정의(예시):** "변호사가 직접 쓰고, 변호사 이름으로 보냅니다. 총액을 미리 알려드립니다."

**카피 후보**
- "보내기 전에 변호사가 한 번 더 읽습니다"
- "추가 비용 없는 총액제 내용증명"
- "상대방이 답이 없으면, 그다음 단계까지 함께 합니다"

**가격 구조 제안 (경쟁사 데이터 기반, 숫자는 직접 정하세요)**

| 플랜 | 내용 | 참고 시장가 |
|---|---|---|
| 검토 발송 | 의뢰인이 쓴 글을 검토해 변호사 명의로 발송 | 7.7만~22만 원 |
| 작성 발송 (주력) | 사연을 받아 변호사가 작성하고 발송, 수정 1~2회 | 10만~33만 원 |
| 상담+작성+사후 대응 | 전화 상담, 작성, 발송, 회신 대응 1회 | 40만~55만 원 |
| 옵션 | 당일 발송, 수신인 추가, 재발송 | 급행은 시장에서 최대 80만 원 |

> ⚠️ 변협 「변호사 광고에 관한 규정」은 **"무료 또는 염가의 수임료" 광고**를 제재 대상으로 넣었습니다. 실제로 "변호사 내용증명 29,900원" 광고를 두고 변호사단체가 변호사법 위반 여부를 조사한 사례도 있습니다. 지나친 최저가 경쟁은 피하고, 광고 문구는 사전에 소속 지방변호사회 기준과 맞춰 보세요.

## 6. 사이트 구조 (사이트맵)

```
/                     메인
/pricing              가격 안내 (총액표, 포함/불포함 항목)
/process              진행 절차 + 처리 시간
/cases                사건 유형별 페이지 (SEO 랜딩)
  /cases/jeonse       전세·월세 보증금 반환
  /cases/loan         빌려준 돈(대여금)
  /cases/payment      물품·용역 대금, 미수금
  /cases/wage         임금·퇴직금 체불
  /cases/contract     계약 해지·해제 통보
  /cases/defamation   명예훼손·모욕 중단 요청
  /cases/received     내용증명을 받았을 때 (답변서)
/apply                신청서 (사연 입력, 파일 첨부, 결제)
/status               진행 조회 (선택)
/guide                칼럼/블로그 (검색 유입용)
/about                변호사 소개 (사진, 등록번호, 원칙)
/faq                  자주 묻는 질문
/legal                이용약관, 개인정보처리방침, 환불 규정
```

### 메인 페이지 섹션 순서
1. **첫 화면:** 한 줄 정의, 대표 가격(총액), [신청하기] / [카카오톡 상담] 버튼
2. **이런 분께:** 사건 유형 카드 6~8개 (아이콘과 한 줄 설명)
3. **가격표:** 3단 플랜, 포함 항목 체크리스트, "VAT·우편료 포함" 표시
4. **진행 절차:** 4단계와 단계별 소요 시간
5. **왜 변호사 내용증명인가:** 셀프·행정사 서비스와 비교 (사실만, 비방 금지)
6. **변호사 소개:** 사진, 이름, 등록번호, 원칙
7. **후기·실적:** 실제 의뢰인 동의를 받은 것만
8. **FAQ:** 효력, 반송, 수정, 환불, 비밀 보장
9. **하단 CTA, 사무소 정보** (사무소명, 대표 변호사, 주소, 사업자번호, 광고책임변호사)

### 신청 폼 항목
- 의뢰인: 이름, 연락처, 이메일
- 상대방: 이름/상호, 주소 (모르면 "모름" 선택 → 초본 발급 안내)
- 사건 유형 (선택), 금액, 기한 희망일
- 사연 (자유 서술 + "언제, 무엇을, 얼마, 지금까지의 연락" 안내 문구)
- 증빙 첨부 (계약서, 이체 내역, 카톡 캡처)
- 발송 방식: 우체국 / 전자 / 둘 다
- 플랜과 옵션 선택, 결제
- 동의: 개인정보 수집·이용(필수), 마케팅(선택)

## 7. SEO / 네이버 유입 키워드 (초안)
- **핵심:** 내용증명, 변호사 내용증명, 내용증명 비용, 내용증명 작성, 내용증명 대행
- **사건형 (전환율 높음):** 전세보증금 내용증명, 월세 보증금 반환 내용증명, 빌려준 돈 내용증명, 미수금 내용증명, 임금체불 내용증명, 계약해지 내용증명, 명예훼손 내용증명
- **정보형 (칼럼용):** 내용증명 효력, 내용증명 반송, 내용증명 무시하면, 내용증명 받았을 때 대처, 내용증명 양식
- **네이버 운영:** 스마트플레이스 등록, 블로그(사건 유형별 칼럼, 주 2~3회), 지식iN 답변, 홈페이지 검색 등록(서치어드바이저)
- **유료 광고:** 파워링크. 키워드 단가는 직접 확인 필요. 2025년 법무부 가이드라인이 입찰식 고액 광고를 규제하려 했지만 구속력은 없는 상태

## 8. 법적·규제 체크리스트 (오픈 전 필수)
- [ ] 「변호사 광고에 관한 규정」 준수: 염가·무료 광고, 결과 보장, 비교 비방 금지
- [ ] **"전문" 표기:** 변협 전문분야 등록이 없으면 "전문 변호사" 표현을 쓰지 말 것 → 사이트 이름에 "전문"을 넣을지 신중히 결정
- [ ] 비변호사 플랫폼 광고 참여 제한 (변협 규정). 크몽 등 입점 전에 확인
- [ ] 광고책임변호사, 사무소 정보 표시
- [ ] 후기·승소 사례: 의뢰인 동의, 개인정보 비식별 처리
- [ ] 개인정보보호법: 처리방침, 수집 동의, 보관 기간, 첨부파일 암호화 보관
- [ ] 전자상거래: 결제(PG), 환불 규정(착수 전후 구분), 사업자 정보 표시
- [ ] 이해충돌 확인 절차 (상대방 이름 조회)

## 10. 준비해 주셔야 할 것
1. 변호사 정보: 이름, 등록번호, 사진, 소속 지방변호사회, 사무소 주소, 사업자번호
2. 확정 가격표 (플랜별 총액, VAT·우편료 포함 여부, 수정 횟수, 환불 규정)
3. 처리 속도 약속 (예: 영업일 24시간 초안)
4. 사이트 이름과 도메인 후보 3개
5. 상담 채널: 카카오톡 채널, 전화, 운영 시간
6. 결제 방식: 카드 PG, 계좌이체
7. 사건 유형별 실제 사례 3~5개 (익명 처리)
