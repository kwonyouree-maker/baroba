# 바로바 — 변호사 내용증명 사이트 (v1 시안)

변호사가 직접 쓰고 변호사 이름으로 보내는 내용증명 서비스의 홈페이지 시안입니다.

## 파일
- `index.html` — 메인 페이지 (사건 유형 11개, 비용, 진행 절차, 변호사 소개, FAQ)
- `intake.html` — 3단계 의뢰서 (유형 → 사연 → 연락처)
- `docs/competitor-research.md` — 경쟁사 조사와 사이트 기획
- `logo-drafts/` — "손투손" 로고 시안 (현재 사이트에는 쓰지 않음)

## 상태
- 점선 밑줄 값은 예시입니다 (변호사 이름, 가격, 연락처, 주소 등).
- 처리 사례 3개는 형식 예시이며 실제 사례로 바꿔야 합니다.
- 의뢰서는 아직 어디에도 전송되지 않습니다 (저장·결제 연동 필요).
- 법 조항과 예시 문구는 공개 전 변호사 검토가 필요합니다.

## 배포
정적 파일 두 개라서 GitHub Pages, Netlify, Cloudflare Pages 어디든 그대로 올리면 됩니다.
